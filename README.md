# Computational Measurement

Physics-informed machine learning for low-cost and

sparse physical measurement systems.


## Current Status

__Exploration / Learning Stage__

Currently focusing on:
- Neural Networks
- PyTorch / JAX
- Automatic Differentiation
- Dynamical Systems
- Inverse Problems
- Physics-informed Machine Learning


## Long-term Goal

Investigate whether physics-informed computational methods
can reduce the hardware requirements of physical measurement
systems while maintaining useful measurement accuracy.


## Repository Structure

- [`CLAUDE.md`](CLAUDE.md) — working instructions for AI-assisted sessions on this repo.
- [`PROJECT_BRIEF.md`](PROJECT_BRIEF.md) — detailed research background, vision, and roadmap.
- [`exploration/`](exploration/) — sandbox for the current Exploration / Learning Stage: disposable notebooks and scripts for building intuition. Kept strictly separate from any future research-project code — nothing here is assumed reusable once the actual research project starts.

The actual research project (once the Exploration Stage ends) will live in its own top-level directory, separate from `exploration/`.
